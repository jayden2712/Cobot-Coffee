# Cobot-Coffee
Control and user interface software for the DMMS collaborative robot coffee system.

Software developed for the DMMS Cobot Coffee project.

## Overview

The system provides a touchscreen user interface for selecting
coffee options and latte art and communicates user selections
to the collaborative robot.

## Setup

1. Clone the repository
2. Create a Python virtual environment
3. Install dependencies

pip install -r requirements.txt

## Run

python main.py

## Project Structure

- UI – touchscreen interface
- Assets – images and icons
- Hardware – robot communication/control
- Config – system configuration
